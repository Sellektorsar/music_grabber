# Основная цель проекта

TelegramAudioDownloader — десктоп-приложение на Python (PyQt6), предназначенное для скачивания аудио из Telegram-каналов через пользовательский аккаунт Telegram (Telethon).

Главный приоритет проекта — стабильность, надежность и удобство использования.

Проект считается рабочим.

Любые изменения должны сохранять существующую функциональность.

# Архитектура

GUI работает только в главном Qt-потоке.

Все обращения к Telegram выполняются только через DownloadThread.

Весь код Telethon работает внутри собственного asyncio event loop.

Связь GUI ↔ поток осуществляется исключительно через Qt Signals.

Запрещается вызывать Telethon напрямую из GUI.
