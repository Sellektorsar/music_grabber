## [1.0.0] — Предрелиз

### Добавлено

#### Функции
- Скачивание аудиосообщений из Telegram-каналов через API (Telethon)
- Три режима: `direct`, `record`, `hybrid`
- Фильтрация по диапазону дат (с/по)
- Аутентификация: телефон → код → двухфакторный пароль
- Превью 5 первых сообщений при старте
- Автопоиск основного канала (если в канале нет аудио — проверяет ссылки из постов)
- Конвертация в MP3 через ffmpeg/pydub
- Запись звука через sounddevice (если прямое скачивание недоступно)
- Отмена загрузки (кнопка «Остановить»)
- Закрытие окна останавливает поток загрузки
- Tooltip'ы для всех полей ввода
- Сохранение/загрузка настроек (JSON-конфиг)
- Файловое логирование (RotatingFileHandler, 5 MB, 3 бэкапа)
- Автоочистка временных `.temp.*` и `.wav` файлов при старте
- Санитизация имён файлов (9 недопустимых символов Windows)
- Проверка ffmpeg перед стартом
- **Отслеживание прогресса скачивания** — панель с просмотренными/аудио/загружено/пропущено/уже есть/ETA/текущий файл

#### Архитектура
- `config.py` — централизованный конфиг с 12 константами
- `queue.Queue` для потокобезопасного обмена данными между GUI и воркером
- `asyncio.to_thread()` для блокирующих операций (конвертация, запись)
- `sd.InputStream` с callback'ом для потоковой записи звука
- `finally`-гарантия закрытия соединения Telethon и удаления WAV

#### Документация
- `ARCHITECTURE.md` — полное описание архитектуры, компонентов, потоков
- `BUILD.md` — инструкции по сборке PyInstaller
- `DEVELOPMENT.md` — настройка окружения, соглашения по коду, расширение
- `TESTING.md` — описание тестов, покрытие, написание новых
- `CHANGELOG.md` — этот файл

- `test_recorder.py` (49) — MIME, is_audio, даты, генерация имён, скачивание с ретраями, cancel

### Изменено

#### Исправления ошибок
- Cancel во время аутентификации: добавлены проверки `_cancel_requested` во все 3 цикла (phone/code/password) — исправлен бесконечный цикл
- `_mime_to_ext`: добавлен `if not mime: return ".ogg"` — исправлен `AttributeError` при None MIME
- Неверный формат даты: читаемое сообщение пользователю вместо падения
- `save_config`: обёрнут в try/except с логированием
- Настройка логирования вынесена из модульного уровня в `setup_logging()` с try/except
- `closeEvent` в MainWindow: остановка потока при закрытии окна

#### Оптимизации
- Замена busy-polling (`asyncio.sleep(0.1)`) на `queue.Queue` — 0% CPU в ожидании ввода
- `sd.rec()` → `sd.InputStream` — потоковая запись без блокировки event loop
- Защита от двойной отправки ответа диалога ввода (флаг `_input_answered`)
- `asyncio.gather(return_exceptions=True)` — сбой одной задачи не ломает остальные
- Удалён дубликат метода `_mime_to_ext` из recorder.py
- Удалены session-файлы из корня проекта
- Прогресс скачивания: счётчики + ETA через `progress_callback` → `progress_signal` → GUI-панель
- Интеграционные тесты (18): полный цикл DownloadThread → recorder → файлы с замоканным Telethon

### Технический долг

- `recorder.py` — God Object, рекомендуется декомпозиция
- Интеграционные сценарии с реальным Telethon не тестируются (замоканы на уровне модуля)
- pydub генерирует SyntaxWarning на `\(` в regex (не наша проблема)
- `pytest-qt` необходим для запуска GUI-тестов
