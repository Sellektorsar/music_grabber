# TelegramAudioDownloader

## Назначение проекта

TelegramAudioDownloader — десктоп-приложение на Python для скачивания аудиофайлов из Telegram-каналов через пользовательский аккаунт Telegram.

Подключение выполняется через Telethon (MTProto).

Приложение не использует Telegram Bot API.

Главная цель проекта — максимально надёжное скачивание аудио даже при нестандартных сценариях работы Telegram.

---

# Основные возможности

Проект поддерживает:

- авторизацию через номер телефона;
- двухфакторную аутентификацию Telegram;
- скачивание аудио из каналов;
- фильтрацию по диапазону дат;
- автоматическое сохранение файлов по папкам дат;
- конвертацию аудио в MP3;
- режимы:
    - direct
    - record
    - hybrid
- повторные попытки скачивания;
- автоматическую очистку временных файлов;
- отмену операций пользователем;
- сохранение пользовательских настроек;
- файловое логирование.

# Важные архитектурные ограничения

GUI никогда не должен выполнять:

- сетевые операции;
- длительные вычисления;
- работу с Telegram API.

GUI отвечает только за отображение информации.

---

Все обращения к Telegram выполняются исключительно внутри DownloadThread.

---

Весь асинхронный код работает через asyncio.

Запрещается создавать дополнительные event loop без необходимости.

---

# Работа с файлами

Все скачанные файлы размещаются внутри:

telegram_audio/

по структуре

telegram_audio/YYYY-MM-DD/

---

Временные файлы обязаны удаляться автоматически.
